# Crudeboys

Crudeboys is a 522-count card collection on doginals, based on a standard 52-card playing deck. Inscriptions #109748927–109768927.

The site is hosted on [Vercel](https://vercel.com).

## Run locally

```powershell
node local-server.js
```

Open [http://localhost:8000](http://localhost:8000).
